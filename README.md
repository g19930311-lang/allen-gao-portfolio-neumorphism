# 高洁 Allen Gao · 个人网站（新拟态 Neumorphism 风格版）

> 本目录是**新拟态风格**的独立副本版本，用于与主版本（蓝白杂志风）对比。
> 主版本仍位于 `../高洁作品集网站/`，两者互不影响。

## 风格说明

**新拟态（Neumorphism）** 的核心是「同色系背景 + 双向柔和阴影」：

- **背景与元素同色**：卡片与页面使用同一底色（浅色 `#e9edf4` / 深色 `#2b3038`），不用边框和色块区分
- **双向阴影**：右下暗影 + 左上高光，营造柔和的浮雕凸起感
  ```css
  box-shadow: 7px 7px 16px rgba(163,177,198,.55),
             -7px -7px 16px rgba(255,255,255,.95);
  ```
- **凸起 = 可交互**：卡片、按钮常态为凸起；按下时变为内凹
- **内凹 = 输入/凹槽**：输入框、进度条轨道、二维码区、数据格使用 `inset` 内阴影

## 主要改造点

| 元素 | 新拟态处理 |
|------|-----------|
| 卡片（作品/生活/服务/证言/联系…） | 去边框 + 同色底 + 浮雕凸起，悬浮时阴影加深 |
| 图片与媒体 | 圆角 + 柔和外阴影，与背景自然融合 |
| 按钮 | 常态凸起；按下变内凹；主按钮保留品牌色双向阴影 |
| 输入框 / 进度条 / 数据格 / 二维码 | 内凹（inset） |
| 原「深色对比区块」 | 并入同色系，改由浮雕层级区分 |
| 时间线轨道 | 改为凹槽 + 凸起节点 |
| 导航滚动态 | 柔光阴影条（取消毛玻璃） |

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面本体（结构 + 样式 + 交互 + 后台，全在一个文件） |
| `site-data.js` | 全站文案与数据（与主版本一致） |
| `assets/` | 图片与简历（形象照、生活照、简历 PDF） |
| `favicon.svg` / `og-image.png` | 标签页图标 / 分享预览图 |

## 使用方式

- **本地预览**：直接双击 `index.html`
- **后台**：页脚「管理后台」（或连点左上角 Logo 三次），默认密码 `allen2024`
- **主题**：右上角按钮可切换 浅色 / 深色（深色下新拟态同样成立）
- **部署**：与主版本相同，可上传到任意静态托管平台

## 与主版本的区别

| | 主版本 | 本副本 |
|---|---|---|
| 视觉风格 | 蓝白杂志风（高对比、清晰边界） | 新拟态（同色系、柔和浮雕） |
| 区分方式 | 边框 + 色块 + 阴影 | 纯阴影（凸起/内凹） |
| 主色 | `#1d4ed8` 沉稳蓝 | `#3d5afe` 蓝紫 |
| 背景 | `#f7f9fc` | `#e9edf4`（冷灰蓝） |
| 适用场景 | 通用、信息密度高 | 作品展示、视觉印象强 |
